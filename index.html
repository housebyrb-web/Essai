House by RB V2

L'estimateur haut de gamme pour cadrer un budget maison.

Cette version pose la nouvelle architecture applicative. Les calculateurs métier seront développés module par module après validation de chaque étape.

    Étape 1

    Identifier la commune du projet

    La commune permet de récupérer le code INSEE, le département et la région. Ces données serviront ensuite aux taxes et aux barèmes locaux.

    Source officielle : API Découpage administratif geo.api.gouv.fr.

    Étape 2

    Qualifier le terrain

    Ces informations alimenteront les frais de notaire, les VRD et le budget global.

    Budget global provisoire
